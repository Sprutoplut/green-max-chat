# Чат MAX через GREEN-API

Одностраничное приложение на React и TypeScript: отправка и получение текстовых сообщений мессенджера MAX. Интерфейс открывается в браузере на вашем компьютере, отдельный сервер поднимать не нужно.

Страницы входа, списка чатов и переписки переключаются по адресу в браузере без перезагрузки:

- `/login` — вход
- `/chats` — список чатов
- `/chats/new` — новый чат по номеру телефона
- `/chats/<chatId>` — переписка

## Что понадобится

- [Node.js](https://nodejs.org/) 20 или новее. Проверка: `node -v`
- npm, он ставится вместе с Node.js. Проверка: `npm -v`
- Аккаунт [GREEN-API](https://green-api.com/max) с инстансом мессенджера MAX
- Телефон с приложением MAX, на котором этот инстанс уже авторизован

## Установка

Склонируйте репозиторий и перейдите в его папку:

```bash
git clone https://github.com/Sprutoplut/green-max-chat.git
cd green-max-chat
npm install
```

## Запуск

```bash
npm run dev
```

В терминале появится строка `Local`. Откройте в браузере именно этот адрес. Если порт 5173 свободен, это [http://127.0.0.1:5173](http://127.0.0.1:5173). Если он уже занят, Vite возьмёт следующий свободный, например [http://127.0.0.1:5174](http://127.0.0.1:5174).

Остановка: в том же окне терминала нажмите `Ctrl+C`.

## Данные GREEN-API

1. Зарегистрируйтесь в личном кабинете GREEN-API и выберите тариф «Разработчик».
2. Создайте инстанс MAX.
3. Авторизуйте его QR-кодом: в приложении MAX откройте Профиль → Устройства → Войти по QR-коду. Для входа по QR в MAX нужно отключить пароль входа. QR можно получить в кабинете кнопкой «Получить QR-код для авторизации».
4. Скопируйте у инстанса два значения: `idInstance` и `apiTokenInstance`.

Адрес API вводить не нужно. Браузер ходит на локальный сервер Vite, а тот пересылает запросы на `https://api.green-api.com`.

При первом входе, если у инстанса не включены входящие уведомления по HTTP API, приложение само включает их и очищает webhook. После такого изменения GREEN-API может перезапустить инстанс, ответы начинают приходить в течение нескольких минут.

## Как пользоваться

1. На странице входа укажите `idInstance` и `apiTokenInstance`, нажмите «Войти».
2. Нажмите «+», введите номер получателя и создайте чат.
   Номер только для России или Беларуси: 11 цифр с `7` или 12 цифр с `375`. Пробелы, скобки и «+» можно не убирать. Номер, записанный с восьмёрки (`8 900…`), будет проверен как `7 900…`.
3. Напишите текст и отправьте его. Получатель увидит сообщение в MAX.
4. Когда получатель ответит текстом в MAX, ответ появится слева в этом чате, пока вкладка открыта. При открытии чата последние сообщения, и исходящие и входящие, запрашиваются методом GetChatHistory.

## Откуда берётся список чатов

Список не хранится в браузере. При каждом открытии страницы он запрашивается у GREEN-API методом [LastOutgoingMessages](https://green-api.com/v3/docs/api/journals/LastOutgoingMessages/).

В список попадают только личные чаты, которым уже отправляли сообщение через API. У такого сообщения в журнале стоит `sendByApi`. Чаты, начатые с телефона, группы и каналы не показываются.

Новый чат появляется в списке после первой отправки через приложение. Пока текст только набран и не отправлен, в журнале API его ещё нет.

Сами сообщения в браузере тоже не сохраняются. История открытого чата каждый раз запрашивается методом [GetChatHistory](https://green-api.com/v3/docs/api/journals/GetChatHistory/): не больше 100 последних текстовых сообщений за 3 месяца. В localStorage остаётся только вход, `idInstance` и `apiTokenInstance`, чтобы не вводить их после обновления страницы. Кнопка «Выйти» этот ключ стирает.

Чтобы проверить приём, оставьте вкладку открытой и ответьте текстом с телефона в MAX. Если новых сообщений нет, GREEN-API завершает ожидание кодом 408. Локальный сервер превращает эту пустую очередь в обычный пустой ответ, поэтому в консоли браузера 408 не появляется.

## Ограничения

- В списке только личные чаты с исходящим сообщением через API. Журнал `LastOutgoingMessages` отдаёт такие сообщения за последние 3 месяца.
- В ленту попадают только личные текстовые сообщения. Картинки, файлы, группы и каналы пропускаются.
- История берётся из GetChatHistory. Сообщения старше 3 месяцев или глубже лимита журнала MAX метод не возвращает.
- Пока вкладка открыта, она забирает очередь уведомлений инстанса. Вторую вкладку этого чата или другой приёмник на том же инстансе одновременно лучше не запускать.
- Один инстанс — один аккаунт MAX. Номер получателя должен быть зарегистрирован в MAX.

## Ветки

Каждая крупная часть лежит в своей ветке. В `main` собрана готовая версия.

- `sprint/01-scaffold` — каркас Vite и оболочка чата
- `sprint/02-auth` — вход по `idInstance` и `apiTokenInstance`
- `sprint/03-send` — чат по номеру и отправка текста
- `sprint/04-receive` — приём ответов через HTTP API
- `sprint/05-readme` — эта инструкция
